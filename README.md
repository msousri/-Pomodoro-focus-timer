# Bloom — A Focus Timer

A Pomodoro timer built around a simple idea: focus should feel like growth, not just a countdown.

**Live demo:** (add your GitHub Pages link here once deployed)

## Concept

Most timer apps show a plain countdown and nothing else. Bloom pairs the countdown with a small flower that opens petal by petal as your session progresses, and every completed focus session plants a tiny flower in a garden strip below the timer.

This shaped the whole design:

1. A purple progress ring that fills smoothly as time passes
2. A blooming flower that mirrors the ring's progress, opening in five stages
3. A growing "garden" of completed sessions, so your daily effort stays visible
4. A calm white and purple palette, kept restrained so the blooming motif stays the one memorable idea

## Features

1. Three modes: Focus, Short Break, and Long Break, with automatic switching
2. A long break unlocks every fourth completed focus session, following the standard Pomodoro rhythm
3. Adjustable session length in one minute steps before starting
4. A gentle two note chime when a session ends
5. A running tally of today's completed sessions
6. Responsive layout and visible keyboard focus states

## Built With

Plain HTML, CSS, and JavaScript. No frameworks and no build step. One file, open it anywhere.

## Design Process

The starting question was what a Pomodoro timer could look like if progress felt organic instead of mechanical. The blooming flower became the signature element early on, and everything else, palette, type, spacing, was chosen to support that single idea rather than add competing detail.
